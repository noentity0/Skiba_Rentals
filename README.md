# SkibaRentals — Full-Stack Booking Platform

**Dec 2025 – Jan 2026**

- Developed and deployed a full-stack rental platform using Node.js, Express.js, MongoDB, and EJS with RESTful CRUD operations.
- Implemented authentication, authorization, session management, image uploads, and review functionality.
- Integrated MongoDB Atlas, Cloudinary, and Render for cloud-based deployment and backend scalability.
